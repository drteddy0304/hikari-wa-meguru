# 写真と光の素材受付

**現行は [Dropbox保存](dropbox/README.md)。以下は採用しなかったGoogle Drive／Sheets案の参考資料で、公開中の構成ではありません。**

Google Drive（非公開）＋Google Sheets＋Apps Script。課金APIや外部DBなし。
**現時点では公開サイトの収集は無効。Googleの実保存・ZIP書き出し・クロスサイト接続は未検証。**

## 保存内容

投稿番号ごとに以下を保存する。画像は公開GitHubへ送らない。

- photo.jpg：選んだ写真を長辺4096px以下に再エンコード。EXIF/GPS・元ファイル名は保持しない。元ファイルそのものではない。
- moon.png：指定範囲を円形に切り抜いた透明PNG（最大2048px）。
- preview.jpg：一覧確認用の縮小画像。
- light.json：色、明るさ、写真上の座標、100粒子、選択範囲、乱数seed、保存画像寸法。
- consent.json：サーバー受付時刻、許諾の版と全文、運営者・連絡先。

PNGはユーザーが指定した範囲であり、月の意味認識・自動審査ではない。印刷用完成デザインではなく、デザイナー向けの色・質感の素材。元写真のピクセル数によって月の切り抜き解像度は小さくなる。

## 設定

1. 運営者のApps Scriptに Code.gs と Bridge.html を保存。appsscript.json は必要スコープの参照用。
2. Google画面でDrive／Sheets／本人照合用メールアドレスの権限を承認し、`setup` を実行。初期設定と書き出しはアクティブユーザーと実行ユーザーの一致を確認する。
3. ログの非公開フォルダ・投稿一覧を確認。初期状態の受付は停止。
4. 運営者名、取下げ窓口、利用許諾と保管・削除方針を確定する。現行 TERMS_ は案。確定した文章に合わせ版を更新。
5. スクリプトプロパティ OPERATOR、CONTACT、TERMS_APPROVED を設定。ENABLED は実検証が済むまで false。
6. Webアプリを所有者として実行する形でデプロイ。一般募集には匿名アクセスが必要。DriveフォルダやSheets自体は非公開のまま。
7. collection-config.mjs の endpoint と enabled を設定する前に、人工画像でGoogleの保存・再送・非公開権限・書き出しを実検証。
8. 本番ONはサーバーの ENABLED とフロントの enabled の両方が必要。運営・連絡先・許諾確定がなければサーバーは受付しない。

別のGoogleアカウントのDriveコネクタを混用しない。キーやOAuthトークンを公開ソースへ入れない。

## 確認とデザイナーへの受け渡し

投稿一覧の「素材フォルダ」または「プレビュー」を開き、「未確認／採用／保留／不採用／取下げ」を選ぶ。写真の内容・権利・月の切り抜き位置は人が確認する。

Apps Scriptの関数 `exportApproved` を実行すると、その時点で「採用」の素材だけを非公開の書き出しフォルダへZIP保存。ZIPはおよそ20MB以下ごとに分割し、素材と許諾記録、manifest.jsonを含む。実行ログのフォルダからダウンロードしてデザイナーに渡す。共有リンクの公開や自動送信はしない。

取下げに変更しても、過去に書き出したZIPや受け渡し済みの複製は自動削除しない。運営側で回収・削除対応が必要。大量投稿の一括書き出しはApps Scriptの実行時間制限があり、実負荷検証前に件数を広げない。

## 上限と失敗時

- 素材合計8MiB/投稿。初期設定は累計1GiB、1日100投稿、Drive残量512MiBを確保。
- 無料サービスの容量・実行割当超過では停止する。無制限運用や可用性を保証しない。
- 保存の成功応答と投稿番号が一致したときだけ受付完了とする。タイムアウトは未確認と表示。
- 再送は同じ番号・内容で照合。同じページでの再試行は重複しない。ページ再読み込み後の再投稿は別番号になる。
- 過去の不完全書き込みは同じIDのフォルダだけをゴミ箱へ移動して再作成。保存後のフォルダ削除・ファイル削除を運営が手動で行った場合、過去の受付票は消えない。
- 公開受付はスパム耐性が限定的。日次上限と容量上限はあるが、人間であることの検証はない。

## 検証

`node --test collection/collection.test.mjs`：停止、許諾、ファイル形式、成功応答、重複、書き込み失敗と復旧、容量、運営者制限をモック環境で確認。
ブラウザ：人工画像から4素材生成、JPEG/PNGデコード、透明な角、100粒子保持、元ファイル名非保持を確認。

未検証：実Google保存、匿名iframe接続、実ZIP、iPhone Safari/LINE・Android Chromeの送信。現時点で受付完了とは報告しない。
