# 山形りお「ひかりは巡る」確認用サイト

ブラウザ内で写真を処理し、12秒の動画を生成します。同意した参加者の写真と調整済み光素材は運営の非公開Dropboxへ保存します。
音源は確認済みのサビ12秒のみ収録。iPhone・Android実機での保存は未検証。

Dropbox保存の設定と検証状況は [collection/dropbox/README.md](collection/dropbox/README.md) を参照。Drive／Sheets保存案は採用していません。

月相は日本時間の2026年11月1日を新月、2027年4月23日を満月として毎日進行。24日以降は満月を維持。動画は当日の月相から始まり、個人の光で残りの暗部の2.5%相当だけ満ちる（その動画のみ）。投稿数や全体進行には加算しない。
