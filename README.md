# 山形りお「ひかりは巡る」確認用サイト

ブラウザ内で写真を処理し、12秒の動画を生成します。写真の送信・収集は行いません。
音源は確認済みのサビ12秒のみ収録。iPhone・Android実機での保存は未検証。

Google Drive＋Sheetsへの写真・光素材の保存機能を準備中。現在は収集OFF。Googleの実保存・匿名受付・ZIP書き出しの検証と許諾確定後に有効化する。設定と確認状況は [collection/README.md](collection/README.md) を参照。

月相は日本時間の2026年11月1日を新月、2027年4月23日を満月として毎日進行。24日以降は満月を維持。動画は当日の月相から始まり、個人の光で残りの暗部の2.5%相当だけ満ちる（その動画のみ）。投稿数や全体進行には加算しない。
